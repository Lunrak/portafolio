# Mi Portafolio Personal

Este es mi portafolio personal como desarrollador web en formación. Estoy cursando una ruta intensiva de aprendizaje que cubre **HTML, CSS, JavaScript, TypeScript, React y React Native**.

**Objetivo:** Convertirme en desarrollador de aplicaciones web y juegos para navegador y dispositivos móviles.

## 🛠️ Tecnologías

| Tecnología   | Estado          |
| ------------ | --------------- |
| HTML5        | ✅ Completado   |
| CSS3         | ✅ Completado   |
| JavaScript   | 🟡 En progreso  |
| TypeScript   | ⏳ Próximamente |
| React        | ⏳ Próximamente |
| React Native | ⏳ Próximamente |

### Habilidades adquiridas en HTML

- Estructura semántica (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Formularios accesibles con validación
- Tablas con datos estructurados
- Multimedia (`video`, `audio`, `canvas`)
- Listas (`ul`, `ol`, `dl`) y anclas de navegación

### Habilidades adquiridas en CSS

- Selectores avanzados (clases, pseudo-clases, pseudo-elementos)
- Modelo de Caja (`margin`, `padding`, `border`, `box-sizing`)
- Flexbox (alineación, distribución, dirección, wrap, anidamiento)
- CSS Grid (layouts bidimensionales, `grid-template-areas`)
- Posicionamiento (`relative`, `absolute`, `fixed`, `sticky`)
- Animaciones con `@keyframes`
- Transiciones y micro-interacciones
- Responsive Design (Mobile First, media queries, `clamp()`)
- Variables CSS (custom properties)

### Habilidades adquiridas en JavaScript

- Variables y tipos de datos (`const`, `let`, `string`, `number`, `boolean`)
- Operadores aritméticos, de comparación y lógicos
- Estructuras condicionales (`if/else`, `switch`, operador ternario)
- Arrays y bucles (`for`, `for...of`, `forEach`)
- Funciones y objetos
- Manipulación del DOM
- Eventos de usuario
- Almacenamiento local (`localStorage`)
- Canvas API para juegos

## 🚀 Cómo ver el proyecto

### En línea

Visita: **[https://Lunrak.github.io/mi-portafolio/](https://Lunrak.github.io/mi-portafolio/)**

### Localmente

1. Clona este repositorio:
   ```bash

   ```
2. Abre el archivo `index.html` en tu navegador.
3. O usa **Live Server** en VS Code para recarga automática.

## 🔧 Flujo de Trabajo con Git

```bash
# Clonar el repositorio
git clone https://github.com/Lunrak/mi-portafolio.git

# Crear rama para nueva funcionalidad
git checkout -b feature/nombre-funcionalidad

# Añadir cambios
git add .
git commit -m "feat: descripción breve"

# Fusionar a main
git checkout main
git merge feature/nombre-funcionalidad

# Subir a GitHub
git push

# Eliminar rama fusionada
git branch -d feature/nombre-funcionalidad
```
